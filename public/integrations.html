Custom Ecommerce Integration Guide

BargainOS is engineered for custom-coded wholesale stores. This guide explains how to install the frontend bargaining widget, communicate with the secure server-to-server API, and enforce negotiated totals during checkout.

Ecommerce Platform Status

To ensure transparency, here is the current availability status of our platform connectors:

Custom-Coded Stores

Available Now

Full support via our embeddable JavaScript widget (/widget.js) and versioned REST API (/api/v1/) for Node.js, PHP, Ruby, Python, and headless platforms.

Planned / Coming Soon

Architecture & Implementation Steps

Step 01 • Frontend Embedding

Embed the BargainOS Widget

Include the lightweight widget script on your cart or checkout page. The data-site-id is your store's public identifier and contains no secrets. Place an optional container where you want the progress banner to render: 

<!-- Add to <head> or before </body> -->
<script src="https://YOUR-BARGAINOS-DOMAIN/widget.js" data-site-id="site_demo_wholesaler" defer></script>

<!-- Place inside your cart template -->
<div id="bargainos-widget-container" data-cart-total="545.00"></div>

When the cart contents change via AJAX in your store, keep the widget synchronized by calling: window.BargainOS.updateCartTotal(newTotal).

Step 02 • Authoritative Cart Valuation

Submit Offers Server-to-Server

Never trust client-supplied subtotals. When the shopper submits an offer through the widget, your backend server reads the authoritative line items from your session/database and transmits them to the BargainOS API using your secret API key: 

POST /api/v1/offers
Host: YOUR-BARGAINOS-DOMAIN
Authorization: Bearer sk_live_YOUR_SECRET_API_KEY
Content-Type: application/json

{
  "items": [
    { "id": "BOX-ECT32-BUNDLE", "name": "Corrugated Cartons (25pk)", "quantity": 2, "unitPrice": 180.00 },
    { "id": "STRETCH-FILM-80G", "name": "Heavy Stretch Wrap (4pk)", "quantity": 1, "unitPrice": 120.00 },
    { "id": "GUMMED-TAPE-10PK", "name": "Kraft Tape (10pk)", "quantity": 1, "unitPrice": 65.00 }
  ],
  "offeredTotal": 475.00,
  "currency": "USD"
}

Example Approved Response (HTTP 200):

{
  "ok": true,
  "offer_id": "off_8b417e3992",
  "status": "accepted",
  "accepted": true,
  "cart_subtotal": 545.00,
  "offered_total": 475.00,
  "min_acceptable_cart": 463.25,
  "discount_amount": 70.00,
  "discount_percent": 12.84,
  "cart_hash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",

  "message": "Offer accepted! You save $70.00 (12.84%) off the standard total of $545.00."
}
Step 03 • Checkout Price Enforcement

Verify and Redeem Offer at Checkout

A generic widget cannot magically rewrite your store's database or payment gateway charges. When your customer reaches the final "Pay / Place Order" step on your website, your backend must:

  1. Verify that the offer_id is valid, unexpired, and not previously redeemed.
  2. Confirm that the line items and quantities currently in the cart match the cart_hash generated during offer approval (ensuring the customer didn't add more items at the discounted price).
  3. Atomically redeem the offer with BargainOS to close it and prevent duplicate redemptions.
  4. Charge the payment processor (e.g., Stripe, Braintree) for the authorized final total.
POST /api/v1/offers/off_8b417e3992/redeem
Host: YOUR-BARGAINOS-DOMAIN
Authorization: Bearer sk_live_YOUR_SECRET_API_KEY
Content-Type: application/json

{
  "items": [
    { "id": "BOX-ECT32-BUNDLE", "name": "Corrugated Cartons (25pk)", "quantity": 2, "unitPrice": 180.00 },
    { "id": "STRETCH-FILM-80G", "name": "Heavy Stretch Wrap (4pk)", "quantity": 1, "unitPrice": 120.00 },
    { "id": "GUMMED-TAPE-10PK", "name": "Kraft Tape (10pk)", "quantity": 1, "unitPrice": 65.00 }
  ]
}

// Success Response:
{
  "ok": true,
  "redeemed": true,
  "offer_id": "off_8b417e3992",
  "redeemed_at": "2026-10-24T14:02:15.112Z",
  "discount_amount": 70.00,
  "authorized_final_total": 475.00
}
