Widget Integration Demonstration

This page demonstrates how an independent wholesale website embeds the BargainOS widget script with a public Site ID to enable automated cart bargaining.

1. Embed Script Tag in Store Theme

Merchants paste this single script tag into their cart or checkout template. The data-site-id is public. 

<!-- BargainOS Automated Bargaining Widget -->
<script src="http://localhost:3000/widget.js" data-site-id="site_demo_wholesaler" defer></script>

<!-- Optional target container for in-page banner -->
<div id="bargainos-widget-container" data-cart-total="540.00"></div>
